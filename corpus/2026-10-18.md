### [DeepSeek 更新 V4.1 Flash 模型并开放搜索接口](https://api-docs.deepseek.com/zh-cn/news/news261017) `#1`

> 10月17日下午约4点，DeepSeek 正式发布并开源了 DeepSeek-V4.1 Flash 的新版本 V4.1-Flash-1017，官方网页端、App 端与 API 已同步更新，API 调用方式和价格不变。DeepSeek 称，新模型在推理、编码和 Agent 任务上有长足提升，尤其增强了从零构建完整项目的能力，同时缩短任务耗时与输出长度，让用户以更低成本完成任务。官方称新模型着重针对 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 等平台框架进行了优化。建议升级到 DeepSeek Harness 0.2.1-rc.1 及以上版本。此次还向公众开放了自研 DeepSeek 搜索引擎的 API，支持多语言搜索，实时返回高相关、高权威、高时效的优质结果。

10月17日，DeepSeek 发布并开源 DeepSeek-V4.1-Flash-1017，官方网页端、App 与 API 已同步切换到新版本，API 调用方式和价格不变，继续使用 deepseek-flash 即可访问。

DeepSeek 称，相比上一版 V4.1 Flash，新模型在推理、编码、Agent 任务和视觉基准上均有长足提升；通过基于自反馈的强化学习训练，新版本增强了在游戏开发、3D 建模等场景从零构建完整项目的能力。同时新模型缩短了任务运行时间与输出长度，让用户以更低成本、更快速度完成任务，本次着重针对 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 等平台做了优化，官方建议升级到 DeepSeek Harness 0.2.1-rc.1 及以上版本。

该模型参数量 7630 亿，上下文窗口 1M tokens，权重以 MIT 许可证开放。DeepSeek 还同步向公众开放自研搜索引擎的 Search 与 Fetch 接口，支持多语言搜索，价格均为 5 元 / 千次；用户在 DeepSeek Harness、Claude Code、Codex 中通过 API 触发的搜索调用目前未计费，将于 11 月 1 日起按次收费。

### [OpenCode 披露安全事件，部分用户受影响](https://x.com/opencode/status/2111519637049319818) `#2`

> OpenCode 称其一个正在停用的旧系统遭未经授权访问，用户存在 OpenCode Console 里的 OpenAI、Anthropic 和 Google 等第三方供应商的 API 密钥可能已暴露。此事与一次大规模蒸馏攻击有关，波及 1.4% 的 Console 用户，均为关联了外部提供商的用户；OpenCode 已通过邮件通知受影响用户，同时正与 Anthropic、OpenAI 和 Google 合作补救。

OpenCode 披露一起安全事件。

OpenCode 在发给受影响用户的通知邮件中称，一个正在停用的旧系统遭到未经授权的访问，保存在 OpenCode Console 的 OpenAI、Anthropic 等第三方提供商 API 密钥可能已暴露。

OpenCode 将事件描述为一次大规模蒸馏攻击，影响了 1.4% 的 OpenCode Console 用户，受影响者为关联了外部提供商的部分用户，已全部通过邮件通知；未收到邮件的用户未受影响。

OpenCode 要求受影响用户撤销并更换密钥，并检查近期用量是否异常；事件仍在处理中，OpenCode 正与 Anthropic、OpenAI 和 Google 合作补救。

Anthropic 工作人员表示，已撤销其认为受影响的 Claude API 密钥，建议曾在 OpenCode 中保存密钥的用户创建新密钥。
